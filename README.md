
# Employee Management System

Веб-приложение для управления персоналом компании и организационной иерархией сотрудников.

Проект разработан в рамках учебного курса ProductStar.

## Возможности

- Просмотр списка сотрудников.
- Поиск сотрудников по полному или частичному ФИО.
- Сортировка по ФИО, должности, зарплате и дате найма.
- Пагинация списка сотрудников.
- Просмотр ФИО руководителя сотрудника.
- Изменение руководителя сотрудника.
- Автодополнение при поиске руководителя.
- Проверка корректности организационной иерархии.
- Защита от назначения несуществующего руководителя и создания циклических связей.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/mrrago7/employee-management-system.git
cd employee-management-system
```

### 2. Создание виртуального окружения

Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка базы данных

Создайте базу данных PostgreSQL и настройте параметры подключения в конфигурации приложения.

### 5. Создание таблиц и заполнение базы данных

Выполните скрипт инициализации базы данных, если он предусмотрен проектом, затем запустите генерацию тестовых данных:

```bash
python seed.py
```

### 6. Запуск приложения

```bash
python -m flask --app app run --debug
```

После запуска приложение будет доступно по адресу:

http://127.0.0.1:5000/employees

## Организационная структура

В приложении предусмотрена пятиуровневая иерархия сотрудников:

1. CEO
2. Manager
3. Team Lead
4. Senior Developer
5. Developer

При изменении руководителя приложение проверяет корректность назначения и сохраняет целостность организационной структуры.
