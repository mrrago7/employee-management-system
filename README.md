# Employee Management System

## Описание проекта

Веб-приложение для управления базой данных сотрудников компании. Приложение разработано на Python с использованием Flask, Flask-SQLAlchemy и PostgreSQL.

База данных содержит 50 000 сотрудников, распределённых по пяти уровням иерархии:
1. CEO
2. Manager
3. Team Lead
4. Senior Developer
5. Developer

## Функциональность

- Просмотр списка сотрудников с информацией о ФИО, должности, дате приёма на работу и зарплате.
- Поиск сотрудников по ФИО.
- Сортировка по зарплате и дате приёма на работу.
- Постраничное отображение списка сотрудников — по 500 записей на страницу.
- Изменение непосредственного руководителя сотрудника с проверкой допустимости подчинения.
- Поиск подходящих руководителей с помощью автодополнения.
- Проверка корректности назначения руководителя: сотрудник не может быть собственным руководителем, а руководитель должен находиться на уровень выше в иерархии.

## Используемые технологии

- Python
- Flask
- Flask-SQLAlchemy
- PostgreSQL
- Psycopg 3
- HTML, JavaScript

## Структура проекта

- `app.py` — маршруты, обработка запросов и логика приложения.
- `models.py` — модель сотрудника и связи между сотрудниками.
- `extensions.py` — инициализация SQLAlchemy.
- `templates/employees.html` — веб-интерфейс приложения.
- `requirements.txt` — зависимости проекта.
- `seed.py` — заполнение базы данных тестовыми данными сотрудников и формирование пяти уровней иерархии.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL-репозитория>
cd <папка-проекта>
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows CMD:

```cmd
.venv\Scripts\activate
```

### 3. Установка зависимостей

```cmd
pip install -r requirements.txt
```

### 4. Настройка PostgreSQL

Создайте базу данных `employee_db` в PostgreSQL.

В файле `app.py` настройте `SQLALCHEMY_DATABASE_URI`, указав имя пользователя, пароль, адрес сервера и порт вашего PostgreSQL.

Для полноценной работы приложения таблица сотрудников должна быть создана и заполнена данными.

### 5. Запуск приложения

```cmd
flask --app app run
```

После запуска откройте в браузере адрес:

`http://127.0.0.1:5000/employees`

## База данных

Основная таблица — `employees`.

Она содержит следующие поля:

- `id` — уникальный идентификатор сотрудника.
- `full_name` — ФИО сотрудника.
- `position` — должность.
- `hire_date` — дата приёма на работу.
- `salary` — заработная плата.
- `manager_id` — идентификатор непосредственного руководителя.

Поле `manager_id` ссылается на `id` в той же таблице, что позволяет хранить иерархию сотрудников.

## API

`GET /employees` — отображение списка сотрудников с возможностью поиска, сортировки и постраничного вывода.

`POST /employees/<employee_id>/manager` — изменение руководителя сотрудника.

`GET /api/managers` — поиск подходящих руководителей для автодополнения.
